🎬 CinemaApp
CinemaApp is a web application designed to provide users with an immersive experience in exploring and booking movie tickets. Built with a focus on user-friendly design and efficient functionality, it offers a seamless interface for movie enthusiasts.

🛠️ Technologies Used
JavaScript: Core functionality and interactivity.
CSS: Styling, including style.css, orderPageStyle.css, paymentStyle.css, and selectDateStyle.css.
HTML: Structure of the web pages.
📂 Project Structure
The project comprises several key files:

index.html: The main landing page.
common.js: Contains shared JavaScript functions.
model.js: Manages data structures and interactions.
moviesController.js & moviesView.js: Handle movie listings and user interactions.
orderPageController.js & orderPageView.js: Manage the ticket ordering process.
paymentPage.js: Handles payment transactions.
selectDateController.js & selectDateView.js: Manage date selection for movie showtimes.
